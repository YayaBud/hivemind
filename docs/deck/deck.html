How it works

Read the logs agents already write. Remember once, recall everywhere.

01
Capture

A daemon on each laptop tails Claude Code and Codex logs; any agent can also write over MCP. Secrets are redacted before anything leaves the file.

02
Per-agent graph

Sessions, prompts, thoughts and replies become one graph per agent, in order, with full or summary reasoning marked.

03
Common graph

Findings, decisions, facts and procedures land in a shared graph, with who wrote them and what they supersede.

04
Recall over MCP

Any agent calls graph_search. Each recall by another agent is saved as a RECALLED edge.

claude -p · codex exec · gemini -p  — your subscriptions do the LLM work. No API key required.
One server · one FalkorDB · one daemon per laptop04

CALL db.idx.fulltext.queryNodes('Memory', $q)
  YIELD node, score
WHERE node.status = 'active'
OPTIONAL MATCH (node)-[r:RECALLED]->()
WITH node, score, count(r) AS uses
RETURN node.id, node.kind, node.text, uses
ORDER BY score DESC, uses DESC
